# Security reporting

This is an experimental firmware updater. Only the latest preview is maintained; older downloads may contain known issues. Hardware validation remains limited to the models and operations identified in the README. No response-time commitment or interrupted-update recovery is provided.

Use [GitHub private vulnerability reporting](https://github.com/danielheimburg/msi-monitor-updater/security/advisories/new). If that option is unavailable, open an issue titled **Private security contact requested**, with no vulnerability details, and wait for a private channel. Do not post exploit details or sensitive records publicly.

Describe the affected release, operating system, model and impact. Start with a minimal redacted description; do not attach full update/preparation records, `monitor.json`, raw HID captures, serial/calibration data, vendor firmware or screenshots showing identifying values and local paths. A maintainer can request narrowly scoped, redacted evidence through the private channel.

Ordinary bugs belong in [GitHub Issues](https://github.com/danielheimburg/msi-monitor-updater/issues); follow the README's reporting guidance. If an update stops, preserve its record locally and keep the monitor connected. Do not repeat a flash to reproduce a bug: restarting the app is not a recovery procedure.
